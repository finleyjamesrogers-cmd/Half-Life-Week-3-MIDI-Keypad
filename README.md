### This is a complete recreation/remake with many changes of the OG project MIDI Keyboard! The major change being... It is now a DRUM PAD!

## The drum pad features:
- 8 hexagon shape exposed copper capacitive touch pads
- 4 tactile clicky buttons
- 1 Rotary Encoder
- Neopixels for the clicky buttons
- Waveshare ESP32-S3-Zero as a core processor!

## Why? 
This project was created to complete week 3 of half life - hack club!
I wanted this to be something that I can relate to more and since that is drumming I decided why not, lets make a drum pad.

## Project Status
The project is fully complete and comes with all the KiCad files, the production files, the basic code, the BOM and this readme!
